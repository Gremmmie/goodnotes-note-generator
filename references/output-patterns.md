# Output Patterns

Use these page archetypes to convert dense material into engaging note pages.

## Pattern A: Concept overview page
Use for definitions, core ideas, or “what is X?”

Structure:
- title
- 1 short definition block
- 3–5 key points
- one mini sketch or conceptual diagram
- one highlighted takeaway

Best for:
- textbook concepts
- theory summaries
- intro pages

## Pattern B: Comparison page
Use for contrasts, classifications, pros/cons, or similar-looking concepts.

Structure:
- title
- 2-column or 3-block comparison
- a few matching bullets per item
- hand-drawn dividers or table lines
- one “how to distinguish quickly” callout

Best for:
- compare A vs B
- subtype comparisons
- methods / models / categories

## Pattern C: Process / workflow page
Use for mechanisms, pathways, step-by-step logic, or experiments.

Structure:
- title
- numbered sequence or arrow chain
- short label under each step
- one small summary box at the end

Best for:
- biological or chemical pathways
- business workflows
- research methods
- chronology / timeline

## Pattern D: Structure / system page
Use for layered structures, frameworks, or component relationships.

Structure:
- title
- center diagram or stacked structure
- labels around the structure
- one short “how parts connect” note

Best for:
- anatomy
- architecture
- model/framework structure
- system components

## Pattern E: Problem → cause → solution page
Use for practical or applied content.

Structure:
- title
- a small “problem” section
- cause bullets with arrows
- solution bullets or steps
- a highlighted final recommendation

Best for:
- study tips
- product / strategy content
- clinical reasoning
- troubleshooting notes

## Pattern F: Summary / cheat sheet page
Use at the end of a set.

Structure:
- title
- compact section blocks
- key formulas / keywords / cues
- one “must remember” box

Best for:
- exam revision
- end-of-chapter recap
- quick review page

## Selection rule
Choose the page pattern that reduces text density the most while preserving meaning.
If two patterns fit, prefer the one that introduces a small sketch or diagram.

## Default set design
For a typical 4-page output:
1. overview or concept page
2. process or structure page
3. comparison or application page
4. summary / cheat sheet page

## Compression tactics
When source material is too long:
- remove repetition
- merge similar bullets
- keep only one example unless examples are the point
- turn explanations into labels
- replace prose with arrow logic
- split into more pages instead of shrinking text
