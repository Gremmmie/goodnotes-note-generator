# Visual Style Reference

Use this file to keep the visual language stable across requests.

## 1) Core look
Create the image like a realistic page from Goodnotes on an iPad, in portrait orientation.

Required feel:
- real handwritten study note
- neat but not mechanical
- clean white page
- educational and friendly
- visually engaging without looking like a poster

Avoid:
- glossy marketing poster style
- magazine layouts
- crowded infographic grids
- overly cute scrapbook decoration
- thick notebook paper textures or yellow paper tones

## 2) Canvas and layout
- Use portrait 3:4.
- Keep visible margins.
- Prefer asymmetrical but balanced placement.
- Leave whitespace between sections.
- Keep one main topic per page.
- Use one dominant reading path from top to bottom.

### Density target
Use a medium-light density.
A good page should feel informative at a glance but should not feel “full.”
If the content becomes cramped, add a page.

## 3) Typography / handwriting behavior
### Chinese
- Use neat, natural handwritten Chinese.
- Favor a semi-print handwriting style rather than cursive chaos.
- Allow slight character-size variation.
- Keep strokes confident and readable.

### English
- Use tidy handwritten print.
- Make English slightly smaller than the main Chinese title if mixed.
- Preserve technical terms exactly.
- Avoid system-font-looking text blocks.

### Mixed-language pages
- Let Chinese carry the main narrative when the source is Chinese.
- Use English for terms, abbreviations, labels, or formulas.
- Keep spacing between Chinese and English visually clean.

## 4) Color system
Use the following palette sparingly:
- deep blue: `#005087`
- light blue: `#86B8CE`
- muted red: `#B23939`
- dusty pink: `#D88080`

Recommended usage:
- titles / title underlines: deep blue
- secondary headings / boxes: light blue
- warnings / emphasis / key conclusions: muted red
- soft highlights / accent labels: dusty pink

Rules:
- Keep most body text black or dark gray.
- Do not flood the page with color.
- Use highlight strokes and thin marker swashes rather than large saturated blocks.

## 5) Hand-drawn elements
Preferred supporting elements:
- arrows
- curly brackets
- circles / loops around keywords
- mini flowcharts
- comparison tables with hand-drawn lines
- tiny icons or doodles
- simplified sketches of objects or concepts
- speech-bubble or label callouts

All supporting elements should feel drawn by hand.
Keep them simple, legible, and educational.

## 6) Realism cues
Use a few of these cues lightly:
- small imperfections in alignment
- slight pen pressure variation
- a few naturally curved lines
- non-uniform marker highlights
- imperfect but clean boxes and arrows

Do not make the page look sloppy.

## 7) Social-friendly composition
Because pages may be posted to Xiaohongshu-like platforms:
- ensure the main title is readable in a feed preview
- avoid tiny body text
- avoid long dense paragraphs
- use visual anchors every few sections
- make each page understandable on its own
- make multi-page sets feel consistent in layout and color behavior

## 8) Final visual test
A good final image should look like:
- a real student or creator carefully wrote it on an iPad
- informative but not exhausting
- easy to pause on and save
- more “premium handwritten notes” than “AI infographic”
